# Setup Guide

Run bootstrap first:

```bash
~/setup/setup/bootstrap.sh
```

Then complete these manual steps in order.

---

## 1. Add SSH Keys

Add your public keys to `~/.ssh/authorized_keys`. Each key on its own line.

From local machine:
```bash
ssh-copy-id -i ~/.ssh/id_ed25519_hp-server sarang@<ip>
```

From iPad (Termius): copy the key from Termius Keychain and paste it:
```bash
echo "ssh-ed25519 AAAA... Generated by Termius" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

---

## 2. Connect to Tailscale

```bash
sudo tailscale up
```

Authenticate via the URL it prints. After that:

```bash
tailscale status   # verify connected
tailscale ip       # get your Tailscale IP (100.x.x.x)
```

Use the Tailscale IP in Termius and other devices for remote access.

---

## 3. Verify SSH Access

From local machine:
```bash
ssh -i ~/.ssh/id_ed25519_hp-server sarang@192.168.1.3
```

From iPad (Termius):
- Host: `100.x.x.x` (Tailscale IP)
- User: `sarang`
- Key: Termius key from Keychain

---

## 4. SSH Config (local machine)

Add to `~/.ssh/config` on your local machine:

```
Host hp-server
    HostName 192.168.1.3
    User sarang
    IdentityFile ~/.ssh/id_ed25519_hp-server
```

Then just use `ssh hp-server`.

---

## 5. SSHFS (local machine only)

Add to `~/.bashrc` on your local machine:

```bash
alias mount-server='sshfs hp-server:/home/sarang ~/mnt/server -o reconnect,ServerAliveInterval=15,ServerAliveCountMax=3'
alias umount-server='fusermount -u ~/mnt/server'
```

See [docs/sshfs-setup.md](../docs/sshfs-setup.md) for full details.

---

## 6. Git Bare Repos (optional)

To use the server as a private Git remote:

```bash
mkdir -p ~/repos/project.git
cd ~/repos/project.git
git init --bare
```

From other machines:
```bash
git remote add origin sarang@hp-server:~/repos/project.git
git push origin main
```

---

## Recovery Checklist

If the system is wiped, run bootstrap then redo steps 1–3 above. Everything else is dotfiles or cloned automatically.
