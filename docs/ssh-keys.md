## SSH Config (local machine)

`~/.ssh/config` maps aliases to keys so you never need `-i`:

```
Host hp-server
    HostName 192.168.1.3
    User sarang
    IdentityFile ~/.ssh/id_ed25519_hp-server
```

Always use named keys — SSH only tries default names (`id_ed25519`, `id_rsa`) automatically. Custom-named keys are ignored without `-i` or a config entry.

## Adding a New Device

**1. Generate a key on the new device:**
```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_<device-name>
```

**2. Copy the public key:**
```bash
cat ~/.ssh/id_ed25519_<device-name>.pub
```

**3. Add it to the server's authorized_keys:**
```bash
echo "ssh-ed25519 AAAA..." >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

**4. Add an entry to `~/.ssh/config` on the new device:**
```
Host hp-server
    HostName 192.168.1.3
    User sarang
    IdentityFile ~/.ssh/id_ed25519_<device-name>
```

**5. Test:**
```bash
ssh hp-server
```

## Adding iPad / Termius

1. In Termius → Keychain → generate or view your key → Export Public Key
2. Copy the full line (`ssh-ed25519 AAAA... Generated by Termius`)
3. On the server:
```bash
echo "ssh-ed25519 AAAA... Generated by Termius" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```
4. In Termius, add a host:
   - Host: `100.100.208.10` (Tailscale IP)
   - User: `sarang` (not the hostname)
   - Key: select from Keychain

## Revoking Access

To remove a device, delete its line from `~/.ssh/authorized_keys` on the server:

```bash
nvim ~/.ssh/authorized_keys
# delete the relevant line and save
```

## Troubleshooting

**Permission denied (publickey):**
- Check the key file exists: `ls ~/.ssh/`
- Check the key name matches `~/.ssh/config` or use `-i` explicitly
- Check the public key is in server's `~/.ssh/authorized_keys`
- Run `ssh -v hp-server` and look for `Offering key` and whether it's accepted

**Key exists but SSH ignores it:**
- SSH only auto-tries default names. Custom names need a config entry or `-i`
- Check `~/.ssh/config` has the correct `IdentityFile` path

**Permissions error:**
```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
chmod 600 ~/.ssh/id_ed25519_*
```
